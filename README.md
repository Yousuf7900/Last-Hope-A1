# TypeScript Assignment

This repository contains solutions for the TypeScript assignment based on problem solving, generics, OOP concepts, interfaces, and type safety.

## Files

- `solutions.ts` → Contains all TypeScript problem solutions
- `blog-1.md` → Blog about `any` vs `unknown`
- `blog-2.md` → Blog about the four pillars of OOP

---

## Topics Covered

- Functions
- Arrays
- String manipulation
- Union types
- Generics
- Interfaces
- Classes and inheritance
- Type safety
- OOP concepts

---

## Language Used

- TypeScript

---

## How to Run

Install TypeScript globally if needed:

```bash
npm install -g typescript
```

Compile the TypeScript file:

```bash
tsc solutions.ts
```

Run the generated JavaScript file:

```bash
node solutions.js
```
